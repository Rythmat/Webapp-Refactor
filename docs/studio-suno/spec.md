# Studio on the Suno frame: spec

Owner direction (2026-10-21): copy as much of Suno Studio's design as possible, in our brand. The source is [`anatomy.md`](anatomy.md), with screenshots cited as **[sNN]**. This spec says what the Studio becomes, region by region, and which of our modules change. The build order is [`prompts/`](prompts/README.md).

## Ground rules

- **Copy layout and behaviour; keep our brand.**
  - **Copy:** structure, proportions, sizes, spacing, radii, elevation, motion, flows, interaction and the colour roles (dark page, pill controls, track-colour identity).
  - **Keep ours:** **Glacial** for all text, with tabular numbers in place of their monospace; Music Atlas tokens and accent; our icons, logo and wording.
  - **Never take** Suno's code, assets, fonts, icons or copy.
- **One interface:** no Simple/Advanced split. The docked panels make it simple by default.
- **Chromebook first:** at 1366×768 (focus mode 1366×655) the frame must hold at least 3 track rows with one docked panel open. Laptop 1477 and desktop 1920 are checked too.
- **Engine untouched:** the store, PlaybackScheduler, collab, persistence (schema 8), harmony core, Prism, Score, Oracle and export are reused. This is a shell and design change, plus new capabilities in S6–S10.

## Music Atlas surfaces in the frame

These are things Suno doesn't have. They go into S12 and S13.

- **Prism:**
  - as a prompt-bar mode ("Suggest chords for these 8 bars") whose results arrive as **takes**;
  - its existing modal is retired;
  - it stays Premium.
- **Chord lane, Insight and sections:**
  - The chord lane and sections lane stay as ruler lanes above the tracks, toggled from the ruler.
  - Insight (key, chords, form) becomes a Library tile, "This song".
- **Score / Lead sheet:** a full-height view replacing the stage, entered from the project menu or the view pill; same top bar.
- **Mix:**
  - Suno has no mixer page; volume and pan live in the headers.
  - We keep Mix as a view (strips 96 px, owner decision), restyled with the new tokens.
- **Teacher tools** (assignments, review, comments; S13): a top-bar pill for "Assignment" or "Review", and a comments lane.
- **Tutorials:** the coach card docks to the Learn system and anchors to the new regions (S14).

## Motion

| Element        | Motion                                                      |
| -------------- | ----------------------------------------------------------- |
| Panels         | Open and close by height, 180 ms ease-out                   |
| Library drawer | Pushes the stage, 200 ms                                    |
| Prompt bar     | Collapses to the sparkle button, 160 ms (scale and opacity) |
| Status card    | Text cross-fades                                            |
| Overlays       | Close at once                                               |
| Reduced motion | Everything becomes an instant swap                          |

## States to build

- **Empty project:** the track column shows "+ Add new track", and the prompt bar suggests a first step.
- **Loading:** waveform placeholder grid, Loading sounds pill.
- **Generating:** status card, streaming take, Stop.
- **Error:** reply card with a retry and the reason.
- **Limits:** quota reached, generation off for this class.
- **Offline:** the prompt bar is disabled and says why; drafts keep working.

## Acceptance (end of S15)

- **Side by side:** each S0–S11 surface next to its [sNN] reference at 1477 px, with the same structure and proportions (±4 px on bars and pills).
- **Chromebook:** 3 or more track rows with one panel open at 1366×655.
- **Rules held:** Glacial everywhere and the design-guard tokens test passes. No Suno asset, string or code is in the repo (`grep -ril suno src/ --exclude-dir=_cache` is empty; the enrichment cache holds unrelated web data).
