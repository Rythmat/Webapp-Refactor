# Classroom v2 — contract deltas

Running list of every backend change the Teacher Office needs, in the order the phases of
[`docs/prompts/teacher-office-complete.md`](../prompts/teacher-office-complete.md) require them.

**How to use this file.** Each phase that needs a server change appends its rows here _and_
writes the schema into [`openapi.yaml`](./openapi.yaml). Every row names the client feature
flag in `src/constants/serverEndpoints.ts` that gates it, so flipping a flag is the only client
change needed when an endpoint ships.

**Two rules that apply to every row:**

1. `npm run predev` regenerates `src/contexts/MusicAtlasContext/musicAtlas.generated.ts` from
   the live swagger. Never hand-edit it, and never import a type for an endpoint that has not
   shipped. Clients for unshipped endpoints live in hand-written adapters under `src/lib/`,
   following the `src/lib/classroom-sessions/api.ts` pattern (authFetch, catch, degrade).
2. The server's Rule 1 firewall check inside `POST /classrooms/{id}/publish` must match object
   **keys exactly** (not as substrings) against the teacher-only field names, and must accept
   the v2 deck keys listed in the P2 row. A substring matcher rejects legitimate keys such as
   `closeable` or `label`.
