# Repeats inside a section: audit

Written 14 October 2026, after Feelin' Alright. Its Verse was one 4-bar line
(C7 C7 F7 F7) written out four times, and every other section was the same.
That chart now has a repeat sign per section with ×4 (×6 for Interlude 2), and
it plays back bar for bar as it did before.

This audit looks for the same thing across all 666 charts: a section whose bars
are one unit written out two or more times in a row. The earlier collapse
(`docs/chart-collapse-report.md`) only looked for whole sections repeated in
turn, so it never saw these.

**Nothing in this report has been changed yet.**

## Summary

440 charts have at least one section like this.

| Tier | What it is                                                                    | Found                                 | Recommendation                                               |
| ---- | ----------------------------------------------------------------------------- | ------------------------------------- | ------------------------------------------------------------ |
| A    | The whole section is a 4- or 8-bar unit repeated, like Feelin' Alright        | 484 sections in 249 songs, 3,256 bars | Apply by script, with the playback check                     |
| B    | The whole section repeats, but the unit is 1, 2, 3, 5, 6 or 7 bars            | 106 sections in 65 songs, 797 bars    | Review: some are real (a 2-bar riff), some are parser blocks |
| C    | The repeat covers only part of the section: bars before it or after it        | 267 sections in 170 songs, 1,395 bars | Review by hand                                               |
| D    | One chord held for bar after bar                                              | 218 sections in 129 songs, 1,419 bars | Leave alone: a held chord is not a repeat                    |
| E    | Inside a repeat that already spans several sections (Feelin' Alright was one) | 46 sections in 36 songs, 275 bars     | By hand: write the passage out, then repeat each section     |

"Bars" is the number of written bars a repeat sign would remove. Playback does
not change. A one-bar riff with two chords in it (1999's F – Gm7/F) counts as a
repeat and is grouped into 4-bar lines. A bar with one chord in it, written
again and again, counts as a held chord (Tier D).

## How a change is made safe

For each section, the repeat sign goes on the unit's first bar. The end repeat
and ×N go on its last bar, and the copies are deleted. The chart then plays
back through `performedBars`, and the result must be identical before the file
is written. Feelin' Alright passed this check: 147 performed bars before, the
same 147 after.

Tier E needs one more step. A section that is already inside a repeat cannot
take its own, because the app has no nested repeats: an end repeat goes back to
the nearest start repeat. The outer repeat is written out as its own sections
(Verse 1, Chorus 1, Verse 2, Chorus 2), and then each one gets its repeat.
