# Hip Hop L2 "Boom Bap" — activity outline (for Aaron's sign-off)

Key **A minor** · tempos 90 / 87 / 90 per progression · house kit · review
triads and inversions, then sus2 and sus4 (D-015). Same rules checklist as L1
(hiphop-L1-outline.md). **agreed** = follows a ledger decision; **draft** =
Claude's proposal.

Chord activities start in C5–C6 (D-032); 8th-note chunking is staccato (D-046).
