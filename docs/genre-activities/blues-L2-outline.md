# Blues L2 “The 12-Bar Blues” — activity outline (for Peter’s review)

Built from Peter’s ICP Studio blues material (BLUES-LEVELS-FOR-MUSIC-ATLAS). Keys: E, G (C Jam Blues in C).
**doc** = the doc’s notes exactly; **adapted** = the doc’s material with the change noted;
**draft** = built from Peter’s rules where ICP has no material yet; **added** = a scale step the Music Atlas format puts before phrases; **moved** = the doc’s material in another key. Authored in `blues_v2.ts`.

- Two styles: the 4/4 Blues Shuffle (l2a: phrases, triad pairs, the boogie) and the Purdie Shuffle in 12/8 (l2b: the half-time shuffle bass, 7-3-5 / 3-7-9, rootless A).
- 12/8 runs at 100 dotted quarters a minute (lesson tempo 150) and plays straight; the doc’s ICP default is 156.
- Blues Band 1’s variations: lessonPairings/blues-l2-shuffle.json and blues-l2-half-time.json.
