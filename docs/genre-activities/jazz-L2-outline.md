# Jazz L2 "Color & Transfer" — activity outline (for Peter’s review)

Built from Peter’s ICP Studio jazz material (JAZZ-LEVELS-FOR-MUSIC-ATLAS). Keys: C.
**doc** = the doc’s notes exactly; **adapted** = the doc’s material with the change noted;
**draft** = built from Peter’s rules where ICP has no material yet; **added** = a scale or arpeggio step the Music Atlas format puts before phrases; **moved** = the doc’s line in another key. Authored in `jazz_v2.ts`.

Everywhere: eighths written straight, swung as ICP plays lines (64%, easing above 130 bpm);
grace notes written on the beat, the note after them a 32nd late; dead (X) bass notes left out,
the note before them held. Jazz Band 1 plays under the play-alongs, its comping written from the
doc’s voicings (Jazz Pianist 1), one variation per chart (lessonPairings/jazz-\*.json).
